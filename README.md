# retail-sales-performance-analysis

## Overview

This project analyzes retail sales transaction data to evaluate business performance across regions, product categories, and customers. 

Using Google Sheets, pivot tables, KPI reporting, and dashboard visualizations, I identified trends and developed insights to support data-driven decision making. 

## Dashboard

- Total Sales: $2.30M
- Total Profit: $286K
- Total Orders: 9.994
- Average Order Value: $229.86

## Regional Analysis

- West generated the highest sales revenue ($725K).
- East generated the send-highest revenue ($679K).
- South generated the lowest sales revenue ($392K).

## Profitability Analysis

- Technology generated the highest profit ($145K).
- Office Supplies generated $122K in profit.
- Furniture generated only $18K in profit, indicating significantly lower profitability than the other categories.
